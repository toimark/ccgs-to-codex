# 设计文档规则（路径范围 AGENTS.md）

完整规则：[../../.claude/rules/design-docs.md](../../.claude/rules/design-docs.md)

在编辑本目录（`design/gdd/**`）下任何文件时，必须遵循：

- 每份 GDD 必须包含 8 个章节：概述、玩家幻想、详细规则、公式、边界情况、依赖关系、调节旋钮、验收标准。
- 公式需含变量定义、期望值范围、示例计算。
- 边界情况要明确说明发生什么；不可写"妥善处理"。
- 依赖关系双向：A 依赖 B，则 B 文档也需提及 A。
- 调节旋钮需指定安全范围与影响面。
- 验收标准必须可被 QA 测试通过 / 失败。
- 不使用含糊措辞；平衡数值需关联公式或理由。
- 设计文档增量编写：先骨架，再逐章节获用户批准后立即写入文件。
