# 叙事规则（路径范围 AGENTS.md）

完整规则：[../../.claude/rules/narrative.md](../../.claude/rules/narrative.md)

在编辑本目录（`design/narrative/**`）下任何文件时，必须遵循：

- 新增设定与现有设定交叉比对，确保无矛盾。
- 每条设定标注正典级别：已确立 / 暂定 / 审核中。
- 角色对话符合该角色的语音档案。
- 世界规则（可能 / 不可能）明确记录并保持一致。
- 悬疑情节需记录"真实答案"，即使玩家永远不会得知。
- 阵营动机、关系、权力结构内部逻辑自洽。
- 文本本地化就绪：不使用无法翻译的习语；变量用命名占位符。
- 单行对话 ≤ 120 字符，以适配对话框约束。
