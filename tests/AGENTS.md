# 测试标准（路径范围 AGENTS.md）

完整规则：[../.claude/rules/test-standards.md](../.claude/rules/test-standards.md)

在编辑本目录（`tests/**`）下任何文件时，必须遵循：

- 测试命名 `test_[系统]_[场景]_[预期结果]`。
- 每个测试需要清晰的 Arrange / Act / Assert 结构。
- 单元测试不依赖外部状态（文件系统、网络、数据库）。
- 集成测试执行后清理自身资源。
- 性能测试指定可接受阈值，超出必须失败。
- 测试数据定义在测试内部或专用 fixture，避免共享可变状态。
- 模拟外部依赖；测试必须快速且确定。
- 每个 bug 修复需附一个能捕获原始缺陷的回归测试。
