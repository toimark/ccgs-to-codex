# 网络代码规则（路径范围 AGENTS.md）

完整规则：[../../.claude/rules/network-code.md](../../.claude/rules/network-code.md)

在编辑本目录（`src/networking/**`）下任何文件时，必须遵循：

- 服务器对所有游戏关键状态拥有权威；**绝不**信任客户端。
- 所有网络消息版本化，支持前向 / 后向兼容。
- 客户端本地预测 + 与服务器协调；为预测错误实现回滚。
- 优雅处理断线、重连、主机迁移。
- 对网络日志做速率限制，防止日志泛滥。
- 同步值必须指定复制策略（可靠 / 不可靠、频率、插值）。
- 定义并跟踪每类消息的带宽预算。
- 验证所有传入数据包的大小与字段范围。
