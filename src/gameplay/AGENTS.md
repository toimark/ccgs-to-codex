# 玩法代码规则（路径范围 AGENTS.md）

完整规则：[../../.claude/rules/gameplay-code.md](../../.claude/rules/gameplay-code.md)

在编辑本目录（`src/gameplay/**`）下任何文件时，必须遵循：

- 玩法数值一律来自外部配置 / 数据文件，**禁止**硬编码。
- 时间相关计算一律使用 `delta time`（帧率无关）。
- 不直接引用 UI 代码；跨系统通信走事件 / 信号。
- 每个玩法系统需有清晰接口；状态机需要明确的转换表与日志。
- 玩法逻辑必须有单元测试，与表现层分离。
- 在代码注释中注明对应的设计文档。
- 不使用静态单例管理游戏状态；用依赖注入。
