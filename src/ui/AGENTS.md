# UI 代码规则（路径范围 AGENTS.md）

完整规则：[../../.claude/rules/ui-code.md](../../.claude/rules/ui-code.md)

在编辑本目录（`src/ui/**`）下任何文件时，必须遵循：

- UI 不持有也不直接修改游戏状态；通过命令 / 事件请求变更。
- 所有面向用户的字符串必须经本地化系统，**禁止**硬编码。
- 交互元素同时支持键鼠与手柄。
- 动画可跳过，并尊重用户的运动 / 无障碍偏好。
- UI 音效通过音频事件系统触发，不直接触发。
- UI 不阻塞游戏线程。
- 可缩放文本与色盲模式是强制要求。
- 在最低与最高支持分辨率下测试。
