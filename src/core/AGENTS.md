# 引擎代码规则（路径范围 AGENTS.md）

完整规则：[../../.claude/rules/engine-code.md](../../.claude/rules/engine-code.md)

在编辑本目录（`src/core/**`）下任何文件时，必须遵循：

- 热路径（更新循环、渲染、物理）零分配；预分配、池化、复用。
- 引擎 API 必须线程安全，或在文档中明确标注为单线程。
- 优化前后必须 profile；记录实测数据。
- 严格依赖方向：引擎 ← 游戏逻辑；引擎代码不得依赖玩法代码。
- 公共 API 文档需带用法示例；破坏性变更要有弃用期与迁移指南。
- 资源使用 RAII / 确定性清理；引擎系统支持优雅降级。
- 编写引擎代码前，先查 `docs/engine-reference/` 当前引擎版本。
