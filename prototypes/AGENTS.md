# 原型代码标准（路径范围 AGENTS.md，宽松版）

完整规则：[../.claude/rules/prototype-code.md](../.claude/rules/prototype-code.md)

本目录（`prototypes/**`）是用于验证想法的可抛弃代码，标准刻意放宽，目标是学习而非生产质量。

## 允许做法

- 硬编码值；最少甚至无文档注释。
- 简单架构：单例、全局状态、复制粘贴均可。
- 调试输出可保留；占位美术 / 音频可使用。

## 仍需遵守

- 每个原型放在独立子目录 `prototypes/[name]/`。
- 每个原型需 `README.md`，记录：验证假设、运行方式、当前状态（进行中 / 已结束）、研究发现。
- 生产代码不得引用或导入 `prototypes/` 中内容。
- 原型不得修改 `prototypes/` 之外的文件，不得部署或发布。

## 原型成功后

- 原型代码不直接迁移到生产；按生产标准重写。
- 原型 `README.md` 的研究发现作为生产设计文档参考。
- 原型目录保留作参考但不再扩展；已结束原型记录发现后归档或删除。
